# Chapter Workflow

ก่อนเขียนทุกบท:
1. อ่าน arc context
2. อ่าน chapter outline
3. อ่าน character files ของตัวละครที่มีบท
4. ตรวจ timeline
5. ตรวจข้อมูลที่ POV รู้
6. ตรวจ reputation และ knowledge ของตัวละครสำคัญ

หลังเขียน:
- บันทึกเหตุการณ์ใหม่ใน arc timeline
- อัปเดต character status หากเปลี่ยน
- อัปเดต knowledge หากมีใครได้รับข้อมูลใหม่
- อัปเดต relationships หากความสัมพันธ์เปลี่ยน
- อัปเดต reputation หากมีพยานหรือข่าวแพร่
- เพิ่ม major event ถ้าเหตุการณ์มีผลระยะยาว
