# ระบบสื่อสารและการแพร่ข่าว

เนื่องจากโลกช่วงต้นเป็นหมู่เกาะ การส่งข่าวมีข้อจำกัดด้านระยะทาง

หอการเดินเรือเจ็ดสมุทรใช้:
- เรือเร็ว
- นกส่งสารในระยะที่เหมาะสม
- สถานีส่งต่อ
- สัญญาณไฟ
- ธง
- จุดสังเกตตามเกาะ

## กฎการเขียน
- ข่าวไม่เดินทางทันที
- ข่าวจากเกาะไกลอาจเก่าเมื่อมาถึง
- ข่าวสามารถถูกบิดเบือนระหว่างทาง
- เส้นทางขาดทำให้ข้อมูลล่าช้า
- ผู้ควบคุมท่าเรือและสถานีข่าวมีอำนาจจากข้อมูล

เวลาเขียนเหตุการณ์สำคัญ ต้องกำหนดว่า:
1. ใครเห็นเหตุการณ์
2. ข่าวออกจากพื้นที่เมื่อใด
3. ส่งผ่านเส้นทางใด
4. ใครได้รับข่าวก่อน
5. ข้อมูลส่วนใดถูกเปลี่ยนหรือหายไป
