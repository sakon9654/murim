## กฎสำคัญ
- ห้ามเปลี่ยนนิสัย วิชา พื้นเพ หรือชื่อเสียงจากข้อมูลในแชทอย่างเดียว
- หากมีการเปลี่ยนข้อมูลถาวร ต้องอัปเดตไฟล์ที่เกี่ยวข้อง
- หากข้อมูลขัดกับ 00-CANON.md ให้ยึด Canon
- ห้ามให้กู้อันรู้ข้อมูลที่ยังไม่อยู่ใน knowledge.md หรือตาม timeline
