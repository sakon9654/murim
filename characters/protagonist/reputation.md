# กู้อัน — Reputation

## Public
สิ่งที่คนทั่วไปในวงการรู้:
- เป็นยอดฝีมือชื่อดัง
- สังกัดหอการเดินเรือเจ็ดสมุทร
- เป็นรองหัวหน้าหน่วยคุ้มกันเส้นทาง
- ใช้ดาบยาวผิดปกติ
- วิชาตัวเบาดีมาก
- เชี่ยวชาญการต่อสู้บนเรือและผิวน้ำ
- มีผลงานคุ้มกันขบวนสำคัญจำนวนมาก
- เคยปราบโจรและช่วยเหลือขบวนเรือในสถานการณ์อันตราย

## Jianghu / คนในวงการ
ภาพรวม:
- เป็นคนที่ไว้ใจได้ในงานจริง
- เก่งในการคุ้มกันและตัดสินใจภาคสนาม
- มีดาบที่ระยะอ่านยาก
- วิชาดาบดูธรรมดาแต่ประสิทธิภาพสูง
- การต่อสู้บนพื้นที่น้ำถือว่าอันตรายมาก

บางคนคิดว่า:
- ชื่อเสียงมาจากงานคุ้มกันมากกว่าการประลอง
- ฝีมือจริงอาจไม่ถึงระดับที่ข่าวเล่า

## Witnesses
คนที่เคยเห็นกู้อันสู้จริงมักประเมินสูงกว่าคนทั่วไป

สิ่งที่พวกเขารู้:
- ระยะโจมตีจริงอ่านยากเพราะมีลมปราณดาบ
- ยิ่งสู้ยืดเยื้อ กู้อันยิ่งปรับตัวได้ดี
- หนึ่งต่อหนึ่งอันตรายมาก
- สองหรือสามคนไม่ได้แปลว่าจะกดเขาได้ง่าย
- วิชาตัวเบาที่เห็นในงานทั่วไปอาจยังไม่ใช่ขีดจำกัด

## Intelligence
รายงานวงในขององค์กรบางแห่งควรมีแนวประมาณ:
- ความสามารถจริงยังประเมินไม่ครบ
- ห้ามใช้ข้อมูลการประลองหรือภารกิจทั่วไปเพียงอย่างเดียวในการประเมิน
- หากต้องปะทะ ควรหลีกเลี่ยงพื้นที่น้ำหรือเรือหากเลือกได้
- ไม่ควรปล่อยให้การต่อสู้ยืดเยื้อโดยไม่เปลี่ยนแผน
- ควรระวังระยะโจมตีเกินกว่าความยาวดาบจริง
- มีความเป็นไปได้ว่ายังมีวิชาตัวเบาหรือวิชาประสานที่ไม่ถูกเปิดเผย

## Truth
ความจริงที่ยังไม่เปิดเผยทั่วไป:
- กู้อันมีวิชาตัวเบาขั้นสูงที่ยังไม่ค่อยใช้
- มีการโจมตีประสานดาบ + ตัวเบา + ลมปราณดาบที่แทบไม่มีใครเคยเห็น
- ขีดจำกัดจริงของการต่อสู้หนึ่งต่อหนึ่งสูงกว่าภาพสาธารณะ
- เขาไม่ได้จงใจซ่อนพลัง แต่ภารกิจส่วนใหญ่ไม่เคยบังคับให้ใช้ทั้งหมด

## กฎการเขียนชื่อเสียง
- ห้ามให้ทุกคนรู้ข้อมูลเท่ากัน
- ห้ามให้ทุกคนดูถูก
- ห้ามให้ทุกคนรู้ว่ามีวิชาโจมตีสูงสุด
- ปฏิกิริยาของคนต้องขึ้นกับแหล่งข้อมูลและประสบการณ์
