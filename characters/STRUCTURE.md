# Character Data Structure

ตัวละครสำคัญควรแยกเป็นโฟลเดอร์เพื่อให้แต่ละแชทอ่านเฉพาะส่วนที่จำเป็น

ตัวอย่าง:

characters/<character-id>/
- profile.md
- personality.md
- speech.md
- combat.md
- reputation.md
- relationships.md
- knowledge.md
- status.md

## หน้าที่แต่ละไฟล์
### profile.md
ข้อมูลพื้นฐาน ประวัติ รูปลักษณ์ สังกัด

### personality.md
นิสัย แรงจูงใจ ความกลัว ค่านิยม จุดอ่อน

### speech.md
น้ำเสียง คำเรียกตนเอง/ผู้อื่น รูปแบบบทพูด สิ่งที่ไม่ควรพูด

### combat.md
อาวุธ วิชา จุดแข็ง จุดอ่อน ไพ่ลับ เงื่อนไขการใช้

### reputation.md
แยกอย่างน้อย:
- ข่าวสาธารณะ
- มุมมองคนในวงการ
- ข่าววงใน
- การประเมินขององค์กร
- ความจริงที่ยังไม่เปิดเผย

### relationships.md
ความสัมพันธ์กับตัวละครและฝ่ายต่าง ๆ

### knowledge.md
ข้อมูลที่ตัวละครรู้ / สงสัย / เข้าใจผิด / ยังไม่รู้

### status.md
สถานะล่าสุด บาดเจ็บ ตำแหน่ง ที่อยู่ และการเปลี่ยนแปลงล่าสุด

## กฎ
ห้ามให้ทุกตัวละครรู้ข้อมูลเท่ากัน
